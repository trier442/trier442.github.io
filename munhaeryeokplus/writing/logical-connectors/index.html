접속어를 많이 쓰면 논리적인 글일까

그러나, 따라서, 반면에 같은 접속 표현을 의미 관계에 맞게 쓰는 방법.

CORE LESSON

핵심 설명

접속어는 문장 사이의 관계를 알려 주는 표지다. 하지만 ‘따라서’를 썼다고 앞 문장이 자동으로 뒤 문장의 원인이 되는 것은 아니다.

접속어를 고를 때에는 실제 관계가 추가인지, 대조인지, 원인·결과인지, 예시인지 먼저 판단해야 한다.

같은 접속어를 반복하기보다 문장 자체의 구조를 분명히 하면 불필요한 연결어를 줄일 수 있다.

EXAMPLE

예시로 이해하기

대조: 그러나, 반면에
결과: 따라서, 그러므로
예시: 예를 들어
양보: 물론 ~하지만
CHECK

직접 점검해 보기

  1. 접속어와 실제 문장 관계가 일치하는가?
  2. ‘따라서’ 앞뒤에 인과관계가 있는가?
  3. 접속어가 없어도 의미가 이어지는 곳은 아닌가?
