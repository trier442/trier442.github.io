쓰기 전에 개요를 만드는 이유

글을 쓰기 전 주장과 근거의 순서를 설계하는 가장 간단한 방법.

CORE LESSON

핵심 설명

바로 문장을 쓰기 시작하면 앞에서 한 말을 반복하거나 결론이 바뀌기 쉽다. 개요는 글의 내용을 미리 설계하는 지도와 같다.

간단한 논술 개요는 ‘주장 → 근거 1 → 근거 2 → 반론 검토 → 결론’ 정도로도 충분하다. 중요한 것은 각 문단이 어떤 역할을 하는지 정하는 것이다.

개요를 만든 뒤 각 문단을 한 문장으로 설명해 보면 글 전체의 논리적 빈틈을 빨리 찾을 수 있다.

EXAMPLE

예시로 이해하기

1문단: 논제 쟁점 제시와 주장
2문단: 학습권을 근거로 설명
3문단: 자율성 반론 검토
4문단: 조건부 제한이라는 결론
CHECK

직접 점검해 보기

  1. 각 문단의 역할이 겹치지 않는가?
  2. 근거 순서가 자연스러운가?
  3. 결론이 처음 주장과 일치하는가?
