# 문해력플러스 (Literacy Plus)

문해력플러스는 일반 사용자를 위한 독서·토론·논술 교육 콘텐츠 사이트입니다.

## 현재 방향
학생 관리나 채점 LMS가 아니라, 누구나 독서논술을 배우고 자료를 활용할 수 있는 공개형 교육 콘텐츠 플랫폼입니다.

## 핵심 메뉴
- 추천도서: 연령별 추천도서 + 책별 생각 질문
- 주제읽기: 인문·사회·과학·미디어 배경지식
- 토론논제: 찬반보다 쟁점과 판단 기준 중심
- 논술쓰기: 주장·근거·문단·반론 등 글쓰기 강의
- 교육가이드: 학생·학부모·교사용 독서논술 지도 자료
- 통합검색: 책, 주제, 논제, 글쓰기 방법 검색

## 콘텐츠 방향
1. 초등 고학년: 질문하는 독서
2. 중학생: 관점 비교와 토론
3. 고등학생: 논증적 읽기와 쓰기
4. 학부모: 가정에서 사용할 수 있는 질문법
5. 교사: 수업 설계와 토론·논술 지도법

## 향후 확장
- 콘텐츠별 고유 URL 및 SEO
- 주제·학년·교과별 태그 아카이브
- 추천도서 100권 이상 구축
- 프린트/PDF 학습자료
- 뉴스레터
- 교사용 수업자료 다운로드
- 검색 유입을 위한 독서논술 칼럼
