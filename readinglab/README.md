# Sophie Reading Lab

독서논술 플랫폼 1차 프로토타입입니다.

## 구현된 기능
- 반응형 홈 화면
- 주제별 독서논술 콘텐츠 3종
- 읽기 → 핵심어휘 → 내용확인 → 사고확장 → 논술쓰기 5단계 학습
- 객관식 즉시 채점 및 해설
- 논술 답안 글자 수 계산
- 논술 초안 자동 저장 / 수동 저장
- 학습 단계 진행률 저장
- 나의 학습 대시보드
- 브라우저 localStorage 기반 저장
